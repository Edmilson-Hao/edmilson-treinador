# Edmilson Treinador

App de treinos personalizados para personal trainers e alunos.

**Acesse:** [edmilson-hao.github.io/edmilson-treinador](https://edmilson-hao.github.io/edmilson-treinador/)

---

## O que o app faz

### Para o Personal
- Cadastrar e gerenciar alunos
- Biblioteca de exercícios (com vídeos do Google Drive)
- Criar rotinas e treinos personalizados
- Receber feedbacks dos alunos
- Controlar planos e pagamentos (manual + PIX)
- Ver estatísticas de adesão

### Para o Aluno
- Ver treinos atribuídos
- Assistir vídeos dos exercícios
- Marcar treino como concluído
- Enviar feedback ao personal
- Acompanhar histórico

---

## Como usar

### Personal
1. Entre com Google
2. Escolha **Sou o Personal Trainer**
3. Copie seu **código de convite** e envie aos alunos
4. Cadastre exercícios e monte as rotinas

### Aluno
1. Entre com Google **ou** e-mail/senha fornecidos pelo personal
2. Digite o **código de convite** do personal
3. Acesse seus treinos e treine!

---

## Tecnologias

- PWA (Progressive Web App) — instalável no celular
- Firebase (Authentication + Firestore)
- HTML, CSS e JavaScript vanilla

---

## Privacidade

Os dados de treinos e alunos ficam no Firebase do personal responsável.  
Cada aluno só acessa os próprios treinos.
